# PSICONEXSOC

Sitio estático de clínica, investigación y divulgación psicoanalítica.

URL actual: https://ljofreflor.github.io/psiconexsoc/

Dominio canónico previsto: `https://psiconexsoc.com`. El correo institucional ya usa ese dominio. Cuando el DNS apunte a GitHub Pages, cambiar `origin` y `base` en `js/site.js`, los `rel=canonical` y el `sitemap.xml`. No añadir un archivo `CNAME` hasta que el dominio responda.

El desarrollo editorial está en [`docs/documento-maestro.md`](docs/documento-maestro.md).
