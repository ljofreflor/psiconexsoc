# PSICONEXSOC

Sitio estático de clínica, investigación y divulgación psicoanalítica.

URL actual: https://ljofreflor.github.io/psiconexsoc/

Dominio canónico previsto: `https://psiconexsoc.com`. Cuando el DNS apunte a GitHub Pages, cambiar `origin` y `base` en `js/site.js`, los `rel=canonical` y el `sitemap.xml`. No añadir un archivo `CNAME` hasta que el dominio responda.

La reserva clínica: `agenda.html` → `cuenta.html` → `panel.html`. El SQL y las funciones están en `supabase/`. Las claves de Supabase y el dominio de Plausible se rellenan en `js/site.js`. El panel del equipo es `equipo-interno.html` (no está en el menú público).

El desarrollo editorial está en [`docs/documento-maestro.md`](docs/documento-maestro.md).
